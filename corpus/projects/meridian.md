# Meridian — brand landing page

A polished, fully responsive brand landing page for a specialty-coffee brand, built from scratch
with no frameworks. Live and deployed.

## What's shipped
- Vanilla HTML, CSS, and JavaScript with a CSS design-token system, fluid typography using
  `clamp()`, and a self-reflowing CSS grid that adapts across devices with almost no media queries.
- Deployed with push-to-deploy on Vercel.

## Design decisions
- No framework on purpose — it demonstrates the fundamentals underneath React: semantic HTML,
  design tokens, and fluid type.
- Responsive via an auto-fit CSS grid instead of media-query sprawl — the layout reflows from the
  CSS itself.

## Why it matters
Frontend fundamentals and craft without leaning on a framework — clean, accessible, responsive, and
deployed. A small piece, kept small on purpose.

**Stack:** vanilla JavaScript, CSS custom properties, `clamp()`, CSS Grid.
